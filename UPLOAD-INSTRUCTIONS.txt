TRACEFRAME — GITHUB PAGES INSTALLATION

1. Open your GitHub traceframe repository.
2. Delete the old repository contents, or replace them with every file from
   this folder.
3. Confirm index.html, app.js, styles.css, contact.css, and favicon.svg are
   visible at the repository root. They must NOT be inside another folder.
4. Open Settings > Pages.
5. Under Build and deployment select:
      Source: Deploy from a branch
      Branch: main
      Folder: /(root)
6. Save and wait for GitHub's deployment to complete.

The repository root must look like:

index.html
app.js
styles.css
contact.css
favicon.svg
README.md
LICENSE
CONTRIBUTING.md

If GitHub still displays the README, index.html is not in the branch and folder
selected under Settings > Pages.
