# Contributing to Traceframe

Traceframe welcomes parsers, test fixtures, documentation and interface improvements.

1. Use only synthetic or explicitly public test data.
2. Preserve original values alongside normalized values.
3. Label inference separately from observation.
4. Add deterministic tests for parser changes.
5. Do not introduce network calls into the local analysis path.
6. Keep exported case formats backward compatible or document migrations.
